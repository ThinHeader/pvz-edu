# 植物大战僵尸 · 拼音/英语/数学学习融合版 — 使用说明

## 一、快速开始

1. 将整个 `pvz-edu` 文件夹拷贝到教室电脑任意位置
2. 双击打开 `index.html`（推荐 Chrome / Edge 浏览器）
3. 无需联网、无需安装任何软件，离线可玩

> 大屏适配：游戏画面会自动缩放并始终完整居中显示（不被任务栏遮挡）。主菜单和游戏内工具栏都有「⛶ 全屏」按钮，课堂教学建议进入全屏模式，再点一次即可退出。支持触屏点击与鼠标操作。

## 二、游戏模式

### 单人生存模式
- 点击植物卡片 → 点击草坪格子 → **答对题目才能种下植物**（消耗阳光，答对另奖励 10 阳光）
- **大嘴花（☀150）**：一口吞掉紧邻格子的僵尸（无论多少血），随后咀嚼消化 3.5 秒，期间无法再咬——适合对付铁桶僵尸
- 直接点击空格子也可以答题，答对后自动召唤植物
- 收集掉落的阳光（点击即可），向日葵会持续生产阳光
- **大波僵尸来袭前会弹题**：答对 → 植物攻击力提升 20 秒；答错 → 植物停火 8 秒（会显示正确答案）
- 每行有一辆小推车作最后防线；撑到倒计时结束即胜利
- 点「⏸ 暂停」会出现明显的"游戏已暂停"遮罩，点遮罩或"继续游戏"按钮恢复；「🏠 退出」会直接返回主菜单
- 数学题答题框自带**屏幕数字小键盘**，平板/触屏大屏无需实体键盘也能作答

### 双人对战模式（同屏分区分答）
- 左侧面板 = 玩家1（植物方），右侧面板 = 玩家2（僵尸方），共享中间战场
- 系统每 7 秒同时给双方出题，**答对自动召唤己方单位**（面板会提示"✅ 召唤了普通僵尸（第 X 行）！+10分"）
- **速度比拼**：每轮先答对的一方获得"战场优势"10 秒（己方单位强化 30%），对方锁定 3 秒
- 连击奖励：植物方 2 连击出双发射手、4 连击出机枪豌豆；僵尸方 3 连击出路障僵尸、5 连击出铁桶僵尸
- 僵尸到达最左侧，植物方基地扣 1 血（共 5 血）；倒计时结束血量 > 0 植物方胜
- 结束后自动生成双方**正确率、平均答题速度**对比报告

## 三、难度设置（开始游戏页面）

| 设置项 | 说明 |
|---|---|
| 学习科目 | 拼音 / 英语 / 数学 |
| 游戏模式 | 单人生存 / 双人对战 |
| 年级难度 | 一年级 ~ 六年级，题目难度随之变化 |
| 僵尸速度 | 慢 / 标准 / 快（低年级建议"慢"） |
| 植物攻击力 | 弱 / 标准 / 强 |
| 英语答题形式 | 四选一（适合触屏）/ 键盘拼写输入 |
| 单局时长 | 2 / 3 / 5 分钟 |

各科目覆盖知识点：
- **拼音**：声母/韵母/整体认读分类、拼读组合、三拼音节、标调规则、汉字注音（内附拼读口诀提示）
- **英语**：小学 1~6 年级核心词汇约 90 词，看英文选中文 / 看中文选英语 / 看中文拼英语
- **数学**：10/20/100 以内加减法 → 表内乘除法 → 四则混合运算 → 小数加减 → 应用题（乘倍、行程）

## 四、自定义题库导入（教师用）

入口：主菜单 →「题库管理」

1. 选择科目（拼音 / 英语 / 数学）
2. 点击「选择 JSON 文件」导入，或直接把 JSON 数组粘贴到文本框
3. 点击「导入」即可；自定义题目会与内置题库**自动混合出题**

### JSON 格式示例

**拼音**（自定义"给汉字选拼音"字库）：
```json
[{"h": "明", "p": "míng"}, {"h": "亮", "p": "liàng"}]
```

**英语**（en=英文, zh=中文, grade=建议年级 1~6）：
```json
[{"en": "dragon", "zh": "龙", "grade": 3}, {"en": "candy", "zh": "糖果", "grade": 2}]
```

**数学**（q=题目, a=答案, kp=知识点标签）：
```json
[{"q": "小明有12颗糖，分给同学一半，还剩几颗？", "a": "6", "kp": "应用题"}]
```

> 清空本科目自定义题：点击「清空本科目自定义题」按钮（不影响内置题库）。

## 五、学习数据统计

入口：主菜单 →「学习统计」

- 记录每一次答题（存本机浏览器，不上传、保护隐私）
- 展示：累计答题数、总正确率、**各知识点正确率与平均用时**
- 自动标出**薄弱知识点**（答题 ≥ 3 次且正确率 < 70%），教师可针对性辅导
- 支持"清空统计数据"

## 七、常见问题

- **双击打开没反应 / 样式错乱**：确认整个文件夹完整拷贝（js、css、images 缺一不可）
- **没有声音**：浏览器首次交互后才会解锁音频，点击一次页面即可；顶栏可静音（改 audio.js 中 muted）
- **触屏没反应**：请使用支持触屏的浏览器（Chrome/Edge），不要使用 IE
- **想打包成 exe 安装包**：可用 Electron/Tauri 将本文件夹打包（代码无需任何改动），教师机上更方便分发
